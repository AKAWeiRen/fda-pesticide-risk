FDA LabClass 與 VioType 正式判讀注意事項
========================================

用途
----
釐清樣本分類、分析紀錄、診斷指標與建模答案。這是本專案的分析界線，不是 FDA 對個別差異案例的法規原因判定。來源欄位定義請對照同目錄 FDA FY2023 官方手冊。

分析單位與標籤
--------------
FY2019–FY2023 的 77,455 筆分析紀錄依 Year + SplNo 聚合成 15,150 樣本。
LabClass 描述樣本的最終實驗室合規分類；VioType 描述單筆殘留的違規類型。
本專案問題是預測樣本的最終不利分類，因此 violative = 1 當且僅當 LabClass == 3，其餘為 0。
N/X 可彙整為 has_n_or_x 診斷指標，不能自動覆寫 violative；二元化也不等於將其餘樣本宣稱安全。

已觀察到的集合
--------------
全部樣本 15,150；LabClass == 3 有 1,336；至少一列 N/X 有 1,682。
含 N/X 但 LabClass != 3 有 346；LabClass == 3 但無 N/X 有 0；兩者都不符合有 13,468。
目前的集合包含關係只是一個資料觀察，不代表兩個欄位定義相同。

不能推論的事項
--------------
數量不能說明那 346 個樣本的 FDA 判定原因，不能猜成複驗、部位、法規程序或資料錯誤。
若需分析差異，應另行查看 Year、LabClass、Type、Portion、SubNo、Remarks 及官方判定資料；沒有證據時只報告觀察，不推論因果或安全性。
不同資料粒度不是欄位的高低階級。先聚合成相同粒度，才可比較集合。

模型界線
--------
VioType、殘留名稱／濃度、檢验完成時間與其他同次檢驗後資訊不能作為同一樣本的預測輸入。
analytical_rows 是來源列數核對，不是殘留次數或風險。聚合表不能代替每筆原始農藥分析內容。
FDA 目標式抽驗結果只支持資料內相對風險，不代表整體市場違規率，也不能直接判定食品安全。
