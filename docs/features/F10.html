目的

Streamlit 模型工作台；保存可核對的結果與限制，供作品集審查和模擬操作。

輸入

F05 CSV、F07 比較 JSON、F08 排序 CSV 與 JSON

輸出

四模型比較、FY2023 排序、個別解釋

方法與資料流

資料流：model_dashboard_data 核對 SHA／schema／答案與特徵→model_dashboard_view；Country／ProdCode 以 AND 篩選，Top20 候選權重 >0，不對篩選子集重算全體指標。歷史答案預設隱藏。

驗收

14,149／10,572／3,577／376，Top20 716／188／50%／2.497905；Afghanistan 29 加 02A01 得空結果且移除舊詳情；Benin 提示 Country 未見，貢獻保留十五位精度。資料唯讀，截距加四欄貢獻還原 logit 容差 1e-10，sigmoid 還原分數容差 1e-12。

技術選擇與替代方案

沿用現有正式模組與保存成果，先核對一致性再呈現；不在展示啟動時重新下載或重訓。相較於啟動時重新計算，可減少依賴與時間，但這不代表跨環境完整重訓已驗證。

限制

FDA 目標式抽驗資料只支持資料內相對風險，不代表整體市場違規率，不能直接判定食品安全。FY2023 已在可行性分析使用，不是全新未觸碰測試集。加權模型 Brier 高於基準，分數未校準；LR 不是最終部署模型。logit 貢獻不是機率百分點、SHAP 或因果效果；AP/ROC-AUC 是保存報告核對。展示不提供新樣本預測、不重訓。
