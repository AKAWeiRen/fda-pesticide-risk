F06：時間切分與常數基準

正式功能說明｜F01–F10 已完成，F11 私有交付進行中；網站僅本機。

目的

時間切分與常數基準；保存可核對的結果與限制，供作品集審查和模擬操作。

輸入

F05 七欄 CSV

輸出

data/results/fda_temporal_baseline.json

方法與資料流

訓練 FY2019–FY2022，測試 FY2023；比例基準只從訓練答案計算，類別字典只來自訓練。同分 Top20 使用均勻抽取期望。

驗收

10,572／933 訓練、3,577／376 測試，重疊 0；基準 0.088252、AP 0.105116、ROC-AUC 0.5、Brier 0.094351；716 名額、Lift 1。

技術選擇與替代方案

沿用現有正式模組與保存成果，先核對一致性再呈現；不在展示啟動時重新下載或重訓。相較於啟動時重新計算，可減少依賴與時間，但這不代表跨環境完整重訓已驗證。

限制

FDA 目標式抽驗資料只支持資料內相對風險，不代表整體市場違規率，不能直接判定食品安全。FY2023 已在可行性分析使用，不是全新未觸碰測試集。加權模型 Brier 高於基準，分數未校準；LR 不是最終部署模型。logit 貢獻不是機率百分點、SHAP 或因果效果；AP/ROC-AUC 是保存報告核對。展示不提供新樣本預測、不重訓。
